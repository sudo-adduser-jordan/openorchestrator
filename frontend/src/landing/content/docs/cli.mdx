title: CLI reference
description: Commands provided by the current Go CLI.
---

The `open-agents` CLI is a thin client for the local Open Agents desktop app and its loopback daemon. Product commands require the desktop app to be running. Run `open-agents <command> --help` for the exact flags supported by your installed version.

## Command tree

```text
open-agents
├── start                         Open the desktop app (download it when needed)
├── stop                          Stop the local daemon
├── status                        Show daemon health
├── doctor                        Check the local Open Agents environment
├── agent ls                      List built-in agent adapters and readiness
├── project                       add, ls, get, set-config, rm
├── spawn                         Create a worker or manager session
├── session                       ls, get, kill, restore, rename, cleanup, claim-pr,
│                                 switch-agent, agent-switch
├── manage <id>                    Move a manager into Manager mode
├── manager ls                     List manager sessions
├── send                           Send a message to a session
├── pr                             merge, resolve-comments
├── review                         ls, trigger, cancel, submit
├── preview                        select/clear a target; start, status, stop a server
├── browser                        Control the selected session browser
├── completion                     Generate shell completions
└── version                        Print build information
```

Internal commands such as `daemon`, `hooks`, `launch`, `agent-process`, and `pty-host` are intentionally omitted.

## Desktop and daemon

### `open-agents start`

Opens the installed Open Agents desktop app. If no app is installed, the legacy launcher can fetch the latest desktop release first. It does not supervise the daemon itself.

| Flag | Purpose |
| --- | --- |
| `--json` | Print the launch result as JSON. |

For a new installation, download the desktop app from the [installation guide](/docs/installation). The frozen npm package is a legacy launcher, not the current distribution channel.

### `open-agents stop`

Asks the loopback daemon to shut down after checking that the run file identifies Open Agents.

| Flag | Purpose |
| --- | --- |
| `--timeout <duration>` | Maximum time to wait for shutdown. |
| `--json` | Print the result as JSON. |

### `open-agents status`

Reports daemon state, process identity, run-file location, health, and readiness. This command does not list sessions.

| Flag | Purpose |
| --- | --- |
| `--json` | Print structured daemon status. |

Use `open-agents session ls` for sessions.

### `open-agents doctor`

Checks Open Agents configuration, the data directory and database, daemon state, Git, GitHub authentication, and the platform runtime (`tmux` on macOS/Linux; ConPTY is built into Windows).

| Flag | Purpose |
| --- | --- |
| `--json` | Print checks as JSON. |

## Projects and agents

### `open-agents agent ls`

Lists the daemon's built-in agent catalog together with local installation and authentication readiness.

| Flag | Purpose |
| --- | --- |
| `--refresh` | Rerun bounded local install/auth probes. |
| `--json` | Print the raw inventory response. |

Agent adapters are compiled into Open Agents. There is no plugin marketplace or `open-agents plugin install` command.

### `open-agents project`

| Command | Purpose |
| --- | --- |
| `open-agents project add` | Register a local Git repository or multi-repository workspace. Scratch is an Open Agents-managed built-in project. |
| `open-agents project ls` | List registered projects. |
| `open-agents project get <id>` | Show one project and its resolved configuration. |
| `open-agents project set-config <id>` | Update typed per-project configuration. |
| `open-agents project rm <id>` | Remove a project registration. |

Project configuration is persisted by the daemon in SQLite. `set-config` supports common flags and `--config-json`; it does not edit `open-agents.yaml`. Use command help for the complete typed fields.

## Sessions

### `open-agents spawn`

Creates a session in a registered project. The command takes no positional arguments and requires a display name.

```bash
open-agents spawn --name fix-login --project my-app --agent opencode --prompt "Fix the login regression"
```

Important flags include:

| Flag | Purpose |
| --- | --- |
| `--name <name>` | Required sidebar name, at most 20 characters. |
| `--project <id>` | Project to use. Otherwise Open Agents resolves environment and current directory context. |
| `--agent`, `--harness <name>` | Override the project's agent. The two names are aliases. |
| `--kind worker\|manager` | Select the session role. |
| `--mode chat\|tui` | Select structured Chat or the agent's native terminal UI. |
| `--branch <name>` | Branch for Git projects. Scratch projects do not support it. |
| `--prompt <text>` | Initial prompt. |
| `--issue <id>` | Associate a tracker issue. |
| `--claim-pr <ref>` | Claim an existing pull request after spawning. |
| `--no-takeover` | Refuse a PR already owned by another active session. |
| `--skip-agent-check` | Skip only the CLI-side install/auth preflight. |

Project resolution order is explicit `--project`, `OPEN_AGENTS_PROJECT_ID`, the project of `OPEN_AGENTS_SESSION_ID`, then the closest registered project containing the current directory. Before spawning, Open Agents refreshes the selected agent's advisory readiness unless `--skip-agent-check` is set.

### `open-agents session`

| Command | Purpose |
| --- | --- |
| `open-agents session ls` | List active worker sessions. Use `--all` for managers and `--include-terminated` for history. |
| `open-agents session get <id>` | Show one session. |
| `open-agents session kill <id>` | Terminate a session. Dirty workspaces are preserved. |
| `open-agents session restore <id>` | Relaunch a terminated session. |
| `open-agents session rename <id> <name>` | Change its display name. |
| `open-agents session cleanup` | Reclaim eligible terminated workspaces; supports `--dry-run`. |
| `open-agents session claim-pr [<session-id>] <pr-ref>` | Attach an existing PR; omitting the session uses `OPEN_AGENTS_SESSION_ID`. |
| `open-agents session switch-agent <id> <target-harness>` | Switch a compatible session to another harness. |
| `open-agents session agent-switch ls <session-id>` | Inspect agent-switch attempts. |

Most lookup commands accept `--project` to disambiguate a session ID.

### `open-agents send`

Sends a message through the daemon to a running session.

```bash
open-agents send --session open-agents-123 --message "Please address the failing test"
```

Both flags are required. When called from a session with `OPEN_AGENTS_SESSION_ID`, Open Agents prefixes the sender identity.

### `open-agents manage <id>`

Moves a manager into Manager mode. Managers start in Manager mode and may
 delegate workers from that mode. A manager in Planning mode can plan but cannot
delegate; workers it delegates start in Planning.

### `open-agents manager ls`

Lists manager sessions. Add `--json` for structured output.

## Pull requests and reviews

| Command | Purpose |
| --- | --- |
| `open-agents pr merge <pr-number>` | Request a merge through Open Agents's GitHub action engine. |
| `open-agents pr resolve-comments <pr-number> [comment-id...]` | Resolve selected or eligible review comments. |
| `open-agents review ls <worker-session-id>` | List review state for a worker. |
| `open-agents review trigger [worker-session-id]` | Start or restart a reviewer run. Aliases: `execute`, `restart`. |
| `open-agents review cancel [worker-session-id]` | Cancel a reviewer run. Alias: `stop`. |
| `open-agents review submit [worker-session-id]` | Submit a reviewer verdict and results. |

Use each subcommand's help for required review-run IDs, verdict values, and file/stdin inputs.

## Preview and browser control

### `open-agents preview [url]`

Selects what the desktop Browser panel displays for the session identified by `OPEN_AGENTS_SESSION_ID`. With no argument Open Agents looks for a supported static entry point in the session workspace; with a file or `file:`, `http:`, or `https:` target it opens that target.

| Command | Purpose |
| --- | --- |
| `open-agents preview clear` | Clear the selected preview. |
| `open-agents preview start [configuration]` | Start exactly one command from `.open-agents/launch.json`, wait for readiness, and select it. |
| `open-agents preview status` | Show the managed preview process and recent bounded logs. |
| `open-agents preview stop` | Stop the managed process tree. |

`.open-agents/launch.json` is optional project configuration. Open Agents does not infer or scaffold development servers, and static files do not require one.

### `open-agents browser`

Controls the live, session-isolated Electron browser owned by the desktop app. It also resolves its target from `OPEN_AGENTS_SESSION_ID`; the desktop app must be open.

The command family includes status/open, accessibility snapshots and references, click/drag/fill/type/press/hover, highlight, scroll, select/check state, property reads, tabs and popups, DevTools, frames, dialogs, waits, screenshots, console/page errors, and bounded opt-in network metadata capture.

References become stale after navigation, DOM replacement, frame changes, or tab changes. Take another snapshot when Open Agents reports `STALE_REFERENCE`. Network capture is off by default, metadata-only, bounded, and automatically expires.

## Shell integration

| Command | Purpose |
| --- | --- |
| `open-agents completion bash\|zsh\|fish\|powershell` | Generate a shell completion script. |
| `open-agents version` / `open-agents --version` | Print build metadata. |

## Environment

| Variable | Default | Purpose |
| --- | --- | --- |
| `OPEN_AGENTS_PORT` | `3001` | Loopback daemon port. |
| `OPEN_AGENTS_RUN_FILE` | `~/.open-agents/running.json` | Daemon identity and port handshake. |
| `OPEN_AGENTS_DATA_DIR` | `~/.open-agents/data` | Daemon data directory. |
| `OPEN_AGENTS_REQUEST_TIMEOUT` | `60s` | REST request timeout. |
| `OPEN_AGENTS_SHUTDOWN_TIMEOUT` | `10s` | Graceful shutdown limit. |
| `OPEN_AGENTS_SESSION_ID` | unset | Current session context for preview, browser, and in-session calls. |
| `OPEN_AGENTS_PROJECT_ID` | unset | Current project context for spawn resolution. |

All current Open Agents application state stays under `~/.open-agents` unless `OPEN_AGENTS_DATA_DIR` or `OPEN_AGENTS_RUN_FILE` overrides it.
